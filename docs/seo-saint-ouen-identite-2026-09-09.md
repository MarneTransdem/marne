# Rattachement de Saint-Ouen-sur-Seine

Après rapprochement des pages locales avec les listes officielles des sept départements hors Paris, une seule commune restait sans correspondance exacte : le slug saint-ouen, libellé Saint Ouen. Les autres éléments non rapprochés sont des départements, la région ou des arrondissements parisiens.

L'[Insee](https://www.insee.fr/fr/statistiques/2011101?geo=COM-93070), consulté le 9 septembre 2026, confirme que Saint-Ouen est devenue Saint-Ouen-sur-Seine le 8 novembre 2018, code INSEE 93070. La correspondance est ajoutée explicitement au département de Seine-Saint-Denis.

Le nom, le titre, la description et le sous-titre principal sont corrigés. L'URL /demenagement-saint-ouen reste inchangée, sans redirection ni nouvelle page. La liste départementale et le fil d'Ariane reprennent le nom officiel et le parent 93. Les mentions courtes de Saint-Ouen dans les textes restent possibles ; le reste du contenu local n'est pas réaudité ici.

Le référentiel couvre désormais 88 communes existantes. Validation : npm run check ; vérifier titre, H1, canonique inchangée, lien départemental et fil d'Ariane visible/JSON-LD. Contrôler les deux pages publiques après déploiement. Pas de gain de classement revendiqué.
