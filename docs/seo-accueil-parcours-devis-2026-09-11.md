# Accueil : clarifier la demande de devis

Le bouton principal annonce désormais le devis gratuit. Dans le mini-formulaire, « Continuer ma demande » décrit la navigation vers le formulaire complet. Une phrase précise que Marne Transdem reçoit la demande après l'envoi du formulaire complet.

La gratuité reste visible dans le titre du mini-formulaire. Les flèches conservent leur taille lorsque le texte passe sur plusieurs lignes.

Le parcours et les événements analytiques existants sont conservés. Le titre SEO, la description, le H1 et la canonique restent inchangés. Cette intervention vise la compréhension du parcours ; elle ne constitue pas une promesse d'amélioration de position dans Google.

Validation : suite `npm run check`, contrôle du HTML généré et vérification après publication. Journal local : `build/check-accueil-devis-2026-09-11.log`.
